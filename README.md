# Weather Forecast Application

This project is a weather forecast web application built using
HTML, Tailwind CSS, and JavaScript.

## Features

- Search weather by city
- Get weather using current location
- Save recent locations using localStorage
- 5-day weather forecast
- Temperature toggle (°C / °F)
- Extreme weather alerts
- Dynamic weather backgrounds

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- WeatherAPI

## Setup Instructions

1. Clone repository
2. Run Tailwind build command
3. Open index.html

## API Used

WeatherAPI.com
